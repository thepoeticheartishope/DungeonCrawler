# Module map (full)

Rules and data (no page/DOM access):

| File | Job |
|---|---|
| `config.js` | Tunable constants and sample data. Never changes at runtime. |
| `state.js` | The one shared `state` object, plus `key(r, c)` and its reverse `parseKey(k)` (→ `{ row, col }`). Grouped by lifetime: `state.settings` (start screen / DEV panel), `state.run` (one run), `state.floor` (rebuilt each floor), `state.battle` (the current fight). |

## How the game moves (full)

How a frame flows (One stick, the default since one stick plan step G, `ideas/one-stick-plan.md`
outside the repo; the start screen's Turns option, `#turnsToggle`, switches it off, and Real time is
then a turns option): controls.js `walkFrame()` runs every animation frame. While `clockMayRun()`, the
round stick's push (dpad.js `initWalkStick`) or the held move keys go to walk.js `walkFree()`: the
light swings round (look.js `swingLook`), the free spot moves at its pace, a new tile runs moves.js
`enterTile()` and a stuck push `bumpInto()` → events → `settleMove(events)` (as a step:
`applyTurnOutcome(events)`, which with the world on the clock only draws, catches the targets up and
runs `tutorialTurn`). Then `worldFrame()` → combat.js `clockFrame(dt)`: the battery by time
(battery.js `drainLight`) and every stick man on its own clock (`moveMinion`, the reach) → events →
`applyTurnOutcome(events, false)`. Every `REALTIME_STEP_MS` the beat (`clockTick` →
`applyTurnOutcome([], true)` → `advanceMonsters({ minions: false })`) runs what still counts in turns:
the boss's light (budget in beats, light.js `lightTurnsFor`), the hunter waking, the ducts. SELECT
fires as below; the dial, reloads, relays, the Struggle, the battle screen and THE UNFOLDING pause it
all, CHARGE.SYS doesn't.

How a turn flows in turns (the Turns option): key/d-pad → `movePlayer()` (controls.js) → `stepPlayer()` (moves.js,
uses `whatBlocks()`) → events → `applyTurnOutcome(events)` → `advanceMonsters()` (combat.js) →
`drawEvents()` (draws both lists, returns the room note) + `lightConsumed()` →
battle screen if an enemy is adjacent, or the chest / a trapped box was walked into → answer → `applyAnswerResult()` (main.js) →
`settleAnswer()` (answers.js) → events → `drawEvents()` (the encounter log) → next boss
question, end of run, or `endEncounter()`.

Reloading and firing are turns too. There is no reloading at
will: bumping an energy cell → `cellFound` → `openReload(false, cell)` → reload panel → question
on the ask screen → `settleReload()` (the cell is used up by the answer). SELECT (one button, or F) →
gunactions.js `pressSelect()`: on a dial READY, then stop; else `fireGun()` → `fire()` (a landed
shot on a minion opens the dial at READY → `readyShot()` → `settleShot()`). With no rounds, a minion reaching the player → `struggleStarted` → Struggle dial; SELECT → READY (`readyStruggle()`), SELECT → `stopStruggleBar()` → `settleStruggle()` (no extra world turn; moving and waiting are held while it shows). A tap on the map only picks the target (the light swings to it); the mouse or a drag aims, Q / E nudge, Space or the look stick turns (a turn); T →
`cycleTarget()` (free); `.` waits. Each ends in `applyTurnOutcome(events)`, which also runs
`refreshGunTarget()` and ends the run if a minion's strike took the last stability.

With Real time on (start screen), the player's actions don't move the world:
`applyTurnOutcome(events)` only draws them and catches the targets up. main.js `clockTick()`
polls `realclock.js` and runs `applyTurnOutcome([], true)` (= `advanceMonsters()`: minions,
hunter, light, turn count) every `REALTIME_STEP_MS`. The clock pauses for the ask screen (a
reload or relay, picked and answered off the map), a shot's dial, the Struggle dial, the battle screen, THE UNFOLDING, the DEV panel, end screens and a hidden tab. It keeps running under CHARGE.SYS (the charger's cost).
