          Paste one item per line as Prompt | Answer, or paste a JSON
          array of {"term","meaning"} objects. You can also load a
          text file instead of pasting. A JSON entry
          may add an "options" array with 2–4 answer choices
          (the correct answer is added in if you leave it out); entries
          without "options" get 3 distractors picked at random
          from the rest of the list — preferring entries with a matching
          "answerType" string, so a wrong answer can't be
          spotted just by looking like a different kind of thing. Types
          group into shapes: nouns ("name", "location", "book", "creature",
          "object", "theology", "term"), "adjective", "verb", "number" and
          "verse" (an address like "Micah 1:1"); when a type runs short,
          wrong answers come from the same shape. Entries marked "draft": true (answers
          still waiting on a one-word rewrite) are matched with other
          drafts first. An optional "source" string
          (a reference or short reasoning) shows up alongside the correct
          answer when "Reveal the correct answer" is on and you miss one.
          An optional "image" field (a URL, or a path relative
          to a bundled set's own folder) displays above the question.
