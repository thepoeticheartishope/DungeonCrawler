Move next to an enemy and it auto-targets — if more than one is adjacent, tap the one you want to hit instead. Type what it stands for to strike. Minions fall in one hit; the boss takes three. Paste one term per line as TERM | Meaning, or paste a JSON array of {"term","meaning"} objects. You can also load a text file instead of pasting. For multiple choice mode, a JSON entry may add an "options" array with 2–4 answer choices (the correct meaning is added in if you leave it out); entries without "options" get 3 distractors picked at random from the rest of the list.
